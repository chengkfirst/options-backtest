## 3. 数据层（data）

- [x] 3.13 实现合成链希腊字母的模型自洽标记与 delta 选约的循环性披露；验证：合成链读出的 delta 带标记
- [x] 3.14 实现美式近似偏差的识别与标注；验证：实值看涨跨除息且时间价值低于分红金额时被标注，虚值/平值不产生噪音标注

- [x] 7.4 实现首次触发判定（止盈、止损、持有期满、剩余到期触底），含同日多条件的确定性优先级；验证：四类触发各一个场景；同日多条件只取其一且被压制原因可查
